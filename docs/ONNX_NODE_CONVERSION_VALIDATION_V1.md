# ONNX 与 Node.js 推理转换验证 V1

**状态：已完成离线转换与本机 Node.js 一致性验证；未获准部署到生产。** 本记录只描述候选模型的可复现转换过程，不包含训练、校准或盲测文本，也不改变线上 `iter5-char-2to4gram` 检测引擎。

## 目的与边界

本次工作将已锁定的本地 BERT 微调候选转换为 ONNX，并验证 Node.js 调用输出是否与 Python 参考实现一致。验证使用 20 条专门编写、未纳入训练、校准或盲测的中文文本夹具。所有转换和测试都在用户授权的隔离训练目录中进行，使用 CPU 推理；未修改显卡伪装、驱动、系统设置或网站生产模型。

| 项目 | 锁定值 |
| --- | --- |
| 来源候选 | `aigc_detector_zhv2_finetune_v1` |
| ONNX 算子集 | 17 |
| ONNX 运行时 | Python `onnxruntime 1.19.2`；Node.js `onnxruntime-node 1.19.2` |
| Node.js 验证版本 | `v20.16.0` |
| 固定夹具数 | 20 条 |
| 运营一致性门槛 | 每条 AI 概率绝对差 **< 0.01** |
| 来源模型保护 | 源检查点只读；导出目录版本化；导出文件记录 SHA-256 |

## 转换结果

FP32 ONNX 文件成功导出并通过 ONNX 模型检查。其文件大小为 **409,306,612 bytes**，SHA-256 为 `9A2557637791C28F4DC5744AFCD5B40B012FEA5FAC7EADD8FCDA8891B14C3239`。Python PyTorch 与 FP32 ONNX 在固定夹具上的最大 logits 绝对差为 `0.00000489`，最大 AI 概率绝对差为 `0.00000072`。

随后以相同夹具运行 Node.js 适配器。Node.js 使用导出词表和 BERT WordPiece 规则构造 `input_ids`、`attention_mask` 与 `token_type_ids`，再以 softmax 第二类概率作为 AI 概率。标准 CPU 会话的最大差异为 `0.0000000615`；低内存 CPU 会话的最大差异为 `0.0000004318`。二者均满足预先锁定的 `< 0.01` 门槛。

| 验证链路 | 最大 AI 概率绝对差 | 门槛 | 结论 |
| --- | ---: | ---: | --- |
| PyTorch → FP32 ONNX | 0.00000072 | < 0.01 | 通过 |
| FP32 ONNX → Node.js 标准 CPU 会话 | 0.0000000615 | < 0.01 | 通过 |
| FP32 ONNX → Node.js 低内存 CPU 会话 | 0.0000004318 | < 0.01 | 通过 |

## 量化尝试与拒绝规则

为了适配线上 512 MB 内存限制，先后尝试了逐张量和逐通道动态 `QInt8` 权重量化。两者都没有满足既定的概率一致性门槛，因此导出工具主动删除了不合格 INT8 产物，并回退保留仅用于本机验证的 FP32 ONNX 文件。没有放宽门槛或替换分数计算方式。

| 动态量化方式 | 最大 AI 概率绝对差 | 门槛 | 处理 |
| --- | ---: | ---: | --- |
| `QInt8`，逐张量 | 0.66546130 | < 0.01 | 拒绝 |
| `QInt8`，逐通道 | 0.30923006 | < 0.01 | 拒绝 |

## 部署资源判定

本机 Node.js 标准会话加载 FP32 ONNX 后 RSS 为 **802.36 MB**。禁用 CPU 内存池与内存模式、关闭图优化并限制为单线程后，低内存会话仍为 **457.38 MB RSS**，其中该值尚未包括现有 Express、tRPC、文档解析、请求并发和日志开销。

> 当前托管运行时的内存上限为 **512 MB**。因此，尽管 Node.js 推理在数值上已通过一致性验证，FP32 产物没有足够的生产内存余量，**不得接入线上检测引擎**。

后续 V2 独立校准和冻结盲测仍可在本机 Node.js 候选上执行，用于确认模型质量；但仅当同时取得合格的低内存产物并通过 V2 预注册门槛后，才可评估生产切换。当前线上继续使用 Iter5，现有回滚快照保持有效。
