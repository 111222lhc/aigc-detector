# 冻结短抒情回归集审计

## 审计目的

用户提供的192字符AI短抒情在网页中被判为6分。为判断这是否只是个别文本而非系统性盲点，本审计额外构建了一个与训练流程隔离的短抒情/生活随笔AI文本集，并以网页**实际部署**的`iter5-char-2to4gram`引擎复测。该集合只用于回归评估，不能回流至训练、阈值调参或模型选择。

## 数据与隔离方式

| 项目 | 记录 |
|---|---|
| 文件 | `/home/ubuntu/aigc_detector/data/regression/short_ai_holdout.jsonl` |
| 样本数 | 33条AI文本 |
| 文本长度 | 126—279字符；全部满足网页入口的120字符最小限制 |
| 生成来源 | `gpt-5-mini`与`claude-haiku-4-5` |
| 题材 | 阳台、桂花、地铁、电脑桌面、长椅、旧笔记本、窗帘、夜间添水等日常片段 |
| 训练隔离 | 每条均标记为`regression_only_never_train`；自动化测试检查其与`short_human_train.jsonl`及`short_ai_train/`不存在精确文本重合 |
| 网页评分路径 | 直接调用`server/detectionEngine.ts`内的`scoreTextWindow`与`analyzeText`，模型版本`iter5-char-2to4gram` |

## 结果

> 在50分阈值下，33条冻结AI短抒情中仅**1条**达到阈值，网页可输入样本的AI命中率为**3.03%（1/33）**。

这项结果并不表示所有AI检测模型、所有短文本或全部AI生成模型的通用水平。该测试没有包含同类人类文本，因而不能给出人类误报率或总体准确率；样本也不是经过盲采样的真实论文集。但它直接表明，当前部署模型在**126—279字符的克制生活随笔/短抒情**范围内存在严重漏检，不能对这类文本提供有意义的初筛。

| 指标 | 结果 |
|---|---:|
| 样本总数 | 33 |
| 网页入口可分析样本 | 33 |
| ≥50分AI命中数 | 1 |
| ≥50分AI命中率 | 3.03% |
| 当前产品结论 | **不适用于短抒情、生活随笔及同类短篇描写的初筛。** |

## 复现与产品处理

评分原始结果保存在`/home/ubuntu/aigc_detector/reports/frozen_short_regression_iter5_web.json`；评分脚本为`server/scoreFrozenShortRegression.ts`。`server/frozenShortRegression.test.ts`将检查样本标记、生成来源多样性、训练文本不重合与网页引擎分数有效性。首页已显著提示该不适用范围，避免用户将低风险颜色误作正面结论。

该证据不会触发为提高此集合分数而训练或替换网页模型。若要改善此场景，后续应预先收集独立的人类与AI短文本盲测集，定义同时控制误报和漏检的验收目标，并在完全独立的第二个冻结集合上复验。
