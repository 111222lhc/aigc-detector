## 总体观察

这份参考报告并不是单纯把网页截图打印出来，而是按照 **A4 归档文档** 的逻辑重新组织内容。它的特点不是炫技，而是“像正式报告”。页面留白大、层级克制、信息位置稳定，且几乎每页都保留统一页眉页脚与页码，读者会自然把它当成一份可提交、可存档的文档，而不是网页导出的副产物。

## 第1页：封面式摘要页

第一页承担的是“总览封面”功能，而不是正文开始。当前可见的关键结构包括：

| 区块 | 作用 | 设计特征 |
|---|---|---|
| 顶部品牌栏 | 标识产品与报告编号 | 左侧品牌，中央/顶部出现报告ID，右侧网站域名，形成正式文档抬头 |
| 主标题 | 明确报告类型 | 大字号标题，副标题为“简明打印版”，强调这是面向打印的版本 |
| 核心指标摘要 | 先给结论 | 将总体疑似度、加权疑似度置于最前，随后给出各风险层级占比 |
| 文档元信息 | 建立归档感 | 包括版本、编号、题目、作者、字数、段落数、句子数、提交时间等 |
| 分布图 | 快速显示风险离散情况 | 使用紧凑的横向柱/条，而不是大图表，适合打印 |
| 图例与说明 | 解释颜色规则 | 直接说明红橙紫黑灰各自含义，并补充统计口径与免责声明 |

这一页给人的最大启发是：**报告第一页应该像“执行摘要页”而不是普通页面头图**。它需要把“这是什么、结论如何、文档是谁、怎么读颜色”一次性交代完。

## 第2页：原文首页 + 页眉页脚

第二页开始进入正文证据部分。参考报告在这一页保留了原文题目、学校/课程抬头、正文起始位置和页脚页码。其核心做法是把“原文内容”作为主要视觉对象，而不是解释性面板。

这一页的重要价值在于，它让读者觉得这份报告和被检文档发生了直接映射关系：不是抽象评分，而是对着论文内容逐页标示。对我们而言，这意味着打印版不能只有统计卡片，还需要更强的“证据页”与“原文对应关系”。

## 第3–5页：高密度证据页

第3到第5页展示的是最核心的检测证据，当前可见设计规律如下：

| 观察点 | 参考报告做法 | 对我们的启发 |
|---|---|---|
| 主体内容 | 以原文段落为中心 | 证据页应以文本本身为主，而不是以组件卡片为主 |
| 高亮方式 | 直接在句段上做底色标注 | 我们当前的“分段明细表”还不够，需要更像“正文批注稿” |
| 风险标签 | 在局部片段旁标示百分比与等级 | 可考虑将分数做成贴边标签、段首标记或页边注释 |
| 分页节奏 | 每页就是正文证据，不夹杂太多解释模块 | 说明页与证据页应分离，避免单页信息类型过杂 |
| 文档连续性 | 保留论文原本的章节结构与阅读顺序 | 应强化“按正文顺序读”的打印路径 |

从当前前五页看，参考报告的核心体验不是“组件丰富”，而是 **摘要页 + 连续证据页** 的文档节奏。换句话说，真正提升美观度的，不是再加几个图，而是让打印版更像一份被设计过的学术审阅材料。

## 初步可复用规则

基于前五页，当前已经可以提炼出以下可迁移规则：

1. **封面页单独存在。** 第一页不应该混入太多正文表格，而应先建立报告身份、编号、文档信息与总览结论。
2. **统计图要小而稳。** 打印图表应优先选择静态、细长、低墨量、可灰度识别的样式，而不是依赖复杂图表库渲染。
3. **证据页是主角。** 后续页面应大量展示原文及对应高亮，而不是重复显示指标卡。
4. **统一页眉页脚。** 每页都应有稳定的报告标题、页码、编号或文档名，增强归档感。
5. **阅读路径固定。** 先摘要、再规则、后证据，避免现在这种网页组件式的跳跃阅读体验。

## 第6–8页：后续正文与结束方式

第6页延续正文证据稿的格式：高亮句段按原文顺序继续出现，章节标题不被卡片或大色块打断。这说明参考报告将“检测结果”嵌入到原文阅读过程里，读者能同时看到上下文与风险提示。

第7页进入结语与参考文献区域，仍有局部高亮，随后以参考文献结束。其设计意义在于：报告不会在所有高风险句段展示完后戛然而止，而是允许被检文档以自然的论文结构收束。第8页则为几乎空白的尾页，只有稳定页脚，可能来自原文排版或导出流程的最后分页。

| 后半段观察 | 对导出报告的影响 |
|---|---|
| 正文高亮贯穿至后续章节 | 证据页必须支持跨页连续正文，而不是只输出排名靠前的片段卡片 |
| 正文章节标题保持原样 | 应保留用户原始标题、段落顺序和标题层级，避免把论文改写成表格清单 |
| 参考文献页仍属于文档证据 | 对于论文场景，报告可保留原文末尾材料并让用户确认分析范围 |
| 页码始终稳定 | 每页都应拥有自有品牌页眉/页脚与“第 X 页 / 共 Y 页”归档标识 |
| 尾页可能为空 | 自有报告应尽量避免无内容尾页，需在打印样式中处理强制分页规则 |

## 完整设计结论

参考报告给出了一个清晰的文档型报告模式：**第1页执行摘要，后续页面为带风险标注的连续原文。** 它把图表压缩到摘要页，将主要版面留给“原文—标注—上下文”的审阅动作。

我们的重构应借鉴这一阅读路径，但不能复制其品牌、文案、商标或专有页面样式。自有报告应使用“文析 AIGC 文本特征评估报告”及现有绿色设计系统，并采用以下结构：

1. **第1页：自有品牌执行摘要。** 包含报告编号、被检文档、模型版本、总体风险、三色分布、检测范围和人工复核说明。
2. **第2页：复核导航。** 包含风险级别说明、优先复核索引、统计分布与方法/边界提示。
3. **第3页起：连续正文证据稿。** 按原文窗口/段落顺序排版，保留原文内容，高风险内容以内嵌底色和页边分值标签标示，不再以宽表格作为主要阅读结构。
4. **尾页：复核记录与免责声明。** 放置重点窗口汇总、复核建议、模型边界以及报告生成信息；避免无内容的强制尾页。

这套结构能提升打印稿的归档感和阅读连贯性，也保持对“文本特征评估而非身份裁决”的透明表述。
