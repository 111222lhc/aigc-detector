# 预训练检测器微调：外部语料来源核验

## DetectRL 的审查结论

2026-08-14 对 DetectRL 官方仓库进行核验。该仓库将其定位为面向真实场景机器生成文本检测的评测基准，并强调不同提示方式、人工修改、拼写攻击和文本混合等设置。[1] 但是，其公开的 `load_dataset.sh` 仅下载 arXiv、XSum、WritingPrompts 与 Yelp Review 原始数据。[2] 该脚本本身并不提供可直接用于本项目中文论文检测微调的中文成对训练数据。

因此，本轮**不把 DetectRL 的原始数据加入微调池**。该决定同时避免将以英文为主的基准与本项目的中文论文/正式写作目标混合，并避免在未完成逐项许可复核前复制下游数据。

| 项目 | 核验结果 | 本轮处理 |
|---|---|---|
| 发布主体 | `NLP2CT/DetectRL` 官方仓库 | 仅作评测设计参考 |
| 公开加载脚本 | arXiv、XSum、WritingPrompts、Yelp Review | 不下载、不并入训练 |
| 中文可直接微调分片 | 官方仓库当前脚本未提供 | 不作为本轮来源 |
| 数据合规状态 | 下游来源与许可需逐项复核 | 不以推断代替许可审计 |

## 本轮数据来源原则

本轮将仅考虑与 Iter5 完整训练清单经规范化哈希比对后无重合的中文人类文档，并为 AI 类创建新的、提示家族隔离的对照文本。冻结 OOD、GPT-5.5 留出、短文本回归、用户反例和 Iteration10 全局留出均继续禁止进入训练或阈值选择。

## DetectRL-ZH 的替代来源线索

在内置模型生成服务暂不可用后，检索发现 NLP2CT 已公开 **NLPCC 2025 Task 1** 项目，并将其描述为面向中文 LLM 生成文本检测的 DetectRL-ZH 基准。[3] 该线索优先于无来源说明的聚合数据集，但在下载任何样本前仍须核验：公开许可、训练/验证/测试分割是否明确、字段是否可追溯、以及与本项目现有 JSONL 的规范化哈希是否无重合。

当前状态是**待下载前核验**；尚未将 DetectRL-ZH 样本并入任何分区，也未假定其许可证允许本项目使用。

后续官方仓库核验显示，该任务描述的训练数据含 32,400 条样本，覆盖 ASAP、CNewSum、CSL 三个来源，以及 GPT-4o、GLM-4-flash、Qwen-turbo 三个生成器；开发集则被官方明确限定为“只可调参、不可训练”。[3] 仓库的许可证 API 返回 `404 Not Found`，即没有可机器识别的许可证声明。因此，本轮遵循“许可不明即不使用”的原则，将 DetectRL-ZH **排除在训练、校准和盲测之外**，不下载其数据文件。

| 核验项 | 结果 | 本轮决定 |
|---|---|---|
| 数据规模与来源 | 32,400 条训练样本；3 个中文领域、3 个 LLM | 仅作研究设计参考 |
| 开发集规则 | 官方限制为调参用途，不可训练 | 不下载、不合并 |
| 仓库许可证 | GitHub 许可证接口返回 `404 Not Found` | 许可不明确，排除 |
| 与现有数据重合 | 未下载，无法且不应假定无重合 | 不使用 |

## 本地 AI 对照生成器的核验

为避免将任何人类文本或用户文件发送到外部服务，本轮选择官方公开的 Qwen2.5-0.5B-Instruct 作为**本机离线**生成器候选。官方模型卡标注其为 Apache-2.0 许可证、0.49B 参数的指令微调因果语言模型，并提供使用 Transformers 在本地加载与生成的示例。[4] 该模型仅接收脚本中固定的抽象公共写作任务；不会读取、上传或提示化用户论文。

该生成器产生的文本只能作为训练和校准中的 AI 类对照。最终一次盲测仍需要与训练生成器和提示家族隔离的来源；在取得第二个许可明确的本地生成器前，不得打开最终盲测文件。
