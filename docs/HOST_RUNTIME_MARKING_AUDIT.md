# 右下角浮动标识来源核验

## 核验结论

对当前首页运行时 DOM 与前端源码进行了检查。`client/src` 中不存在 `Manus` 或 `manus` 的用户可见文案、图标或组件引用；页面根节点内也不存在固定定位的浮动品牌元素。

页面运行时会加载以下宿主相关脚本：`__manus__/debug-collector.js`、内联 `#manus-runtime` 以及分析脚本。这些脚本由开发预览/托管运行时在项目根节点外注入，不是本项目 React 组件树中的节点。用户看到的右下角浮动 Manus 图标因此属于托管环境或管理界面层，而不是可以在本项目源码中安全删除的页面内容。

## 处理范围

本项目已经使用自有的“文析 AIGC 检测”品牌，网页正文、页脚和导出报告均不含 Manus 产品文案。保留托管环境注入的图标或管理入口，避免通过 CSS 遮挡、DOM 删除等方式规避平台运行时标记。若用户需要独立域名、独立托管或完全自定义的访问环境，应在导出代码后选择自行部署的托管方案。
