# 检测报告数据模型

系统将一份文档视为一份不可变的**检测报告**。报告保存聚合AI生成特征风险、模型版本、文档来源类型及统计分布；每个段落或长段落内的检测窗口保存为一个**检测分段**。上传原文件不保存在数据库中，文本只在检测请求内使用；持久化内容仅保留用户主动保存报告时的分段正文与评分结果。

| 实体 | 关键字段 | 用途 |
|---|---|---|
| `detectionReports` | `userId`、`title`、`overallScore`、`riskLevel`、`modelVersion` | 报告索引、历史查询和模型可追溯性 |
| `detectionSegments` | `reportId`、`position`、`content`、`score`、`riskLevel` | 三色标注、可解释的疑似片段列表及报告重建 |

> **分级规则：** 评分为0–100的“文本生成特征风险分”，其中红色为70–100、橙色为30–69、绿色为0–29。该指标反映模型对文本模式的统计判断，不用于确认作者身份或作出学术诚信处罚结论。

每个历史查询均按 `userId` 过滤；报告详情按报告ID与请求用户双重过滤。检测接口可处理未登录用户的临时文本，但只有已登录用户可保存并查看历史报告。
