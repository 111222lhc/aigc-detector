# 文析 AIGC 检测系统使用说明

## 使用流程

在首页输入文档标题后，可直接粘贴正文，或导入 **TXT、DOCX、PDF** 文件。系统会先在浏览器中提取正文，随后按约600字符的文本窗口进行特征评分。文本不得少于120个字符，单份文件最大为10 MB，单次检测正文上限为70,000字符。扫描型PDF若没有文字层，需要先完成OCR或改为粘贴正文。

检测完成后，报告呈现整体AI文本特征风险分、红橙绿三色窗口分布、原文窗口明细，以及需要优先人工复核的橙色或红色片段。红色对应70%及以上、橙色对应30%至69%、绿色对应29%及以下。可使用报告页的“打印”按钮调用浏览器打印或另存为PDF。

| 场景 | 系统行为 |
|---|---|
| 未登录检测 | 允许完成临时检测；正文和结果不保存到历史记录。 |
| 登录后保存 | 用户主动点击“保存报告”后，将保存报告汇总和分段结果，并可在“报告历史”中按当前账户查看。 |
| 文件解析失败 | 显示明确提示。可确认文件未加密、未损坏，或改用文本粘贴。 |
| 文件格式或大小不符合要求 | 仅接收TXT、DOCX、PDF，且拒绝超过10 MB的文件。 |
| 短文本或过长正文 | 分别提示至少120字符，或建议按章节拆分至70,000字符以内。 |

## 评分解释与边界

该系统使用在隔离测试集上进行过迭代评估的字符n-gram文本模型，对文本与训练语料中“生成文本特征”的接近程度进行风险评估。报告分数不是作者身份确认，也不应单独用于学术诚信或纪律处置。人工复核时应结合写作过程、版本记录、引用来源、实验材料及其他可验证证据。

系统在固定隔离测试集上的最终实验记录为：人类文本误报率约3.2%，AI文本漏检率约16.1%。长篇旅行文体、强人工改写、极短文本、引用密集文本及人机混合写作仍可能导致更高不确定性；这些场景应尤其避免根据单一分数作出结论。

## 隐私与保存

未登录检测的正文仅用于当前检测请求。登录用户选择保存后，系统保存报告元数据、三色分布和分段评分，以便该用户查看历史报告。系统不会将检测结果呈现为对作者的确定性判断。
