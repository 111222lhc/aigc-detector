# 用不起知网大学生的选择

> 一个面向论文写作前自查的 **AIGC 文本特征初筛工具**。它帮助用户定位值得人工复核的段落，辅助修改与完善写作过程；**不是降重服务，不替代学校要求使用的检测系统，也不能据此认定作者身份。**

## 它能做什么

项目支持导入或粘贴 TXT、DOCX、PDF 格式的论文正文，并基于已训练的中文字符 n-gram 文本特征模型完成窗口级评分。检测完成后，首页只保留总体风险摘要与关键提示；完整报告则在独立页面中展示三色风险分布、逐窗口证据、重点复核区、CSV 明细下载和 A4 PDF 打印导出。

| 能力 | 说明 |
|---|---|
| 文档导入 | TXT、DOCX、PDF；浏览器端提取正文 |
| 窗口分析 | 按约 600 字符窗口评分，而非简单关键词匹配 |
| 风险报告 | 总体风险分、红橙绿窗口分布与优先复核段落 |
| 导出归档 | 独立报告页、CSV 明细下载、浏览器打印为 A4 PDF |
| 报告保存 | 登录用户可将主动选择保存的报告写入个人历史 |

## 正确使用方式

建议把它当成“提交前的初筛”：先阅读总体风险摘要，再进入详细报告查看需要优先复核的窗口，结合自己的草稿版本、引用来源、实验材料和写作过程进行修改。完成自查后，仍应根据学校或期刊的具体要求，使用指定系统进行最终复核。

本工具不会把任何分数表述为“作者确定为 AI”或“可以通过某个官方系统”。它的输出仅表示文本与模型训练语料中生成文本特征的接近程度。

## 已知边界

当前网页部署模型为 `iter5-char-2to4gram`。在固定隔离测试中的实验记录约为：人类文本误报率 **3.2%**、AI 文本漏检率 **16.1%**。这些是特定评估集上的实验结果，不是对任何单篇论文的保证。

**短抒情、生活随笔、极短文本、强人工改写、引用密集文本与人机混合写作**均可能带来较高不确定性。尤其是 126—279 字符的短抒情 AI 回归集，当前模型在 50 分阈值下只命中 1/33 条；请勿将本工具用于该类文本的可靠初筛，更不能把低分理解为确定的人类写作结论。

## 本地运行

本项目使用 React、TypeScript、Express、tRPC、Drizzle ORM 和 MySQL。请先准备 Node.js 22+、pnpm 与 MySQL/TiDB 兼容数据库。

```bash
pnpm install
pnpm dev
```

生产构建与质量检查：

```bash
pnpm check
pnpm test
pnpm build
```

数据库连接、OAuth 和内置服务地址通过环境变量注入；请勿将真实密钥、用户正文或生产数据库凭据提交到公开仓库。
